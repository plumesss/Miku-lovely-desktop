首次公开源码版本，包含 macOS（Swift / AppKit）与 Windows（Electron）两套实现。

当前功能（需自行准备已授权素材）：

- 透明悬浮桌宠、点击互动、拖动移动，以及标准、Q 版、蜡笔三套形象配置。
- 动态表情、本地语音和音量驱动口型、投喂大葱、预设台词聊天、心情变化及整点问候。
- 外观与声音设置、登录后自动启动、Open-Meteo 天气查询及天气 / 季节特效。
- macOS 另有送礼物、便签、功能面板及 50 分钟休息提醒；Windows 提供托盘入口。
- MIT 代码许可、资源准备文档及排除本机文件的源码导出工具。

本次仅发布源码和文档，不包含角色图片、音频、图标或安装包；下载后需要按[资源说明](https://github.com/plumesss/Miku-lovely-desktop/blob/v0.1.0/docs/ASSETS.md)准备资源。素材再分发授权尚未核实；聊天使用本地预设台词。

已通过 JavaScript 语法检查、Python 解析、macOS Swift 5 语言模式编译及源码包敏感信息检查。原生代码仍有并发隔离相关编译警告，尚未验证 Swift 6 语言模式；完整 GUI 冒烟检查、Windows 实机测试及 Intel / macOS 13 实机验证尚未完成。
