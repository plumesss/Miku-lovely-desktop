# v0.1.1 · macOS / Windows 无语音安装版

首次提供可以直接安装的 macOS Universal DMG 和 Windows x64 NSIS EXE。保留三套初音形象，移除全部 10 段原语音；无语音资源时关闭声音控件及试听入口。原 v0.1.0 源码标签保持不变。

- 透明桌宠、点击拖动、三套形象、动态动作、表情、投喂、预设文字聊天、心情变化、整点问候和天气 / 季节特效。
- macOS 另含功能面板、送礼物、便签和休息提醒；Windows 提供托盘菜单。
- 通用 macOS 构建脚本、Windows 资源同步脚本、实际 ASAR 校验及 Windows 安装 / 冒烟 / 卸载流程。
- Electron 更新至 44.9.3，更新 fast-uri，修复依赖审计发现的问题。

安装：macOS 打开 DMG 后拖入“应用程序”；Windows 运行 Setup.exe 安装向导。更新前先退出旧程序。最终用户无需 Swift、Python、Node.js 或 npm。
